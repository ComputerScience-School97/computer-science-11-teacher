## Урок 1 — теорія (з проектором, комп'ютери учнів закриті)

### 0–10 хв. Одна змінна — один учень. А якщо їх 36? 🗣

Поверни до дня 11. Там була змінна на один гурток:

```typescript
const clubName = "Програмування";
const room = "215";
```

Питання класу: **а якщо гуртків вісім?** `clubName1`, `clubName2`, `clubName3`?

Розверни абсурд: як тоді вивести всі назви? Як порахувати, скільки їх? Як додати дев'ятий?

Це та сама розмова, що в дні 7 про поля `club_id_1`, `club_id_2`. Нагадай про неї — вони пам'ятають, і паралель працює.

### 10–22 хв. Масив — список значень 🗣

```typescript
const rooms = ["215", "108", "302", "спортзал"];

console.log(rooms.length);   // 4
console.log(rooms[0]);       // "215"
console.log(rooms[3]);       // "спортзал"
```

Три речі, які треба сказати явно:

**1. Нумерація з нуля.** Перший елемент — `[0]`, останній — `[length - 1]`. Це вони вже бачили в `process.argv` у дні 11, тому нагадай про це — не нова ідея.

**2. Перебір циклом:**

```typescript
for (const room of rooms) {
    console.log(`Кабінет: ${room}`);
}
```

Скажи, що це коротша форма циклу спеціально для списків: «для кожного `room` зі списку `rooms`». Звичайний `for` з дня 12 теж працює, але цей читабельніший.

**3. Тип масиву:**

```typescript
const rooms: string[] = ["215", "108"];
const counts: number[] = [14, 10, 12];
```

`string[]` читається як «список рядків».

### 22–35 хв. Об'єкт — один запис 🗣

Тут головний перехід дня. Питання класу:

> Ми хочемо зберігати не просто назви гуртків, а всю інформацію: назву, кабінет, день, місткість. Як?

Хтось запропонує чотири окремі масиви. Розбери, чому це погано: `rooms[2]` і `names[2]` мають описувати той самий гурток, і якщо десь зіб'ється порядок — дані зіпсуються. Це знову надлишковість, тільно в коді.

```typescript
const club = {
    name: "Програмування",
    room: "215",
    maxStudents: 14
};

console.log(club.name);
console.log(club.maxStudents);
```

> **Об'єкт** — один запис із названими полями.

⚠ **Проведи паралель із базою явно.** Напиши на дошці:

| SQL | TypeScript |
|---|---|
| таблиця | масив |
| рядок таблиці | об'єкт |
| поле / колонка | властивість об'єкта |
| `SELECT name FROM clubs` | `club.name` |

Це не метафора, а буквально те саме. У дні 15 вони побачать, що драйвер бази повертає **масив об'єктів** — рядки таблиці як список записів.

**Масив об'єктів:**

```typescript
const clubs = [
    { name: "Програмування", room: "215", maxStudents: 14 },
    { name: "Робототехніка",  room: "108", maxStudents: 10 },
    { name: "Волейбол",       room: "спортзал", maxStudents: 20 }
];

for (const club of clubs) {
    console.log(`${club.name} — ${club.room}`);
}
```

Скажи: **це і є таблиця в пам'яті програми**. Саме такий вигляд мають дані, які прийдуть з бази.

### 35–45 хв. type — опис форми даних 🗣

Мотивація перед синтаксисом. Покажи на проекторі помилку, яку TypeScript не ловить:

```typescript
const clubs = [
    { name: "Програмування", room: "215", maxStudents: 14 },
    { name: "Робототехніка", rooom: "108", maxStudents: 10 }   // друкарська помилка!
];
```

Питання класу: що станеться при `clubs[1].room`? Відповідь: `undefined`, і програма не впаде, а просто виведе дурницю.

```typescript
type Club = {
    name: string;
    room: string;
    maxStudents: number;
};

const clubs: Club[] = [
    { name: "Програмування", room: "215", maxStudents: 14 },
    { name: "Робототехніка", rooom: "108", maxStudents: 10 }   // ❌ підкреслено
];
```

> `type` — це опис форми даних. «Об'єкт типу `Club` має рівно ці поля, рівно таких типів».

Дві переваги, які варто назвати:

1. Друкарська помилка видна **до запуску**
2. Автодоповнення: набираєш `club.` і VS Code показує поля

⚠ Обов'язково скажи вголос: **`type Club` — це та сама робота, що `CREATE TABLE clubs`**. Опис структури перед роботою з даними. Вони це вже робили в дні 6, тільно для бази.

`Club[]` читається як «список об'єктів типу Club».

## Урок 2 — практика

Учні працюють за `day-13-student.md`. Головна частина — реалізація трьох SQL-операцій кодом.

### Мостик, який тримає весь урок

У практиці учні роблять руками те, що вміє SQL:

| SQL із блоку 1 | Код у дні 13 |
|---|---|
| `WHERE weekday = 'середа'` | цикл + `if` |
| `ORDER BY max_students DESC` | цикл + порівняння |
| `COUNT(*)` | накопичення в змінній |
| `SUM(max_students)` | накопичення в змінній |

Це не вправа для вправи. Скажи класу прямо: **тепер ви знаєте два способи розв'язати ту саму задачу, і в дні 15 обидва зійдуться разом** — база віддасть дані, а програма їх обробить.

### На що дивитись, обходячи клас

1. **Нумерація з нуля.** `clubs[3]` при трьох елементах дасть `undefined`. Помилки не буде — програма виведе `undefined` і піде далі. Найпідступніша річ дня.
2. **`clubs.length` проти останнього індексу.** Класична помилка «на одиницю» з дня 12, тепер у новому вигляді.
3. **Крапка з комою в `type`.** Усередині `type` поля розділяються `;`, а в об'єкті — `,`. Це різне, і це збиває.
4. **Забувають описати `type` до масиву.** Порядок у файлі має значення: спочатку `type`, потім змінна.

### Що показати на проекторі перед початком (3 хвилини)

Створи `type`, потім масив об'єктів, потім набери `clubs[0].` і покажи автодоповнення. Далі зроби друкарську помилку в назві поля й покажи, як TypeScript її ловить. Це найпереконливіша реклама типів, яку можна дати.

## ⭐ Зіркове завдання

У файлі учня: `filter`, `map`, `sort` як готові інструменти (після того, як зробили руками), необов'язкові поля через `?`, вкладені об'єкти.

⚠ Не давай `filter`/`map` до того, як вони зробили те саме циклом. Інакше вони запам'ятають заклинання, а не механіку.

## Що піде не так

- **`undefined` замість помилки.** Головна складність дня. Звертання до неіснуючого індексу або поля не ламає програму — вона просто виводить `undefined`. Порада класу: якщо бачиш `undefined`, перевіряй індекс і назву поля по літерах.
- **Кома проти крапки з комою.** У `type` — `;`, в об'єкті — `,`. VS Code підкреслить, але повідомлення буде незрозумілим.
- **Сортування руками виявиться складним.** Це нормально й передбачено: у файлі учня завдання на пошук максимуму, а не повне сортування. Повне сортування — зіркове.
- **Плутають масив і об'єкт.** `clubs[0]` — об'єкт. `clubs` — масив. `clubs.name` не працює, `clubs[0].name` працює. Розбери це з класом уголос, коли з'явиться в першої пари.
- **Копіюють масив із прикладу й не змінюють дані.** Вимагай, щоб дані відповідали **їхній** базі з блоку 1 — це готує день 15.
