## Урок 1 — теорія (з проектором, комп'ютери учнів закриті)

### 0–15 хв. Чому наш проект не можна просто «залити на хостинг» 🗣

Постав питання, яке клас точно поставить сам:

> Що потрібно, щоб ваш сайт відкривався з телефона по адресі,
> а не тільно на `localhost:3000`?

Збери відповіді, потім розбирай по частинах. Малюй на дошці, що взагалі є в системі:

```
   ┌─────────────────────────────────────────────────┐
   │  ВАШ КОМП'ЮТЕР                                  │
   │                                                 │
   │  ┌───────────┐   ┌──────────┐   ┌────────────┐  │
   │  │ web/      │   │ server.ts│   │ SQL Server │  │
   │  │ статика   │   │  Node    │   │  база      │  │
   │  └───────────┘   └──────────┘   └────────────┘  │
   └─────────────────────────────────────────────────┘
```

Тепер питання по кожній частині: **де це житиме в інтернеті?**

| Частина | Що потрібно | Безкоштовно? |
|---|---|---|
| `web/` — HTML, CSS, JS | статичний хостинг | ✅ так, багато варіантів |
| `server.ts` — Node | сервер, що працює постійно | ⚠ обмежено |
| **SQL Server** | СКБД, що працює постійно | ❌ **немає безкоштовно** |

⚠ Ось причина. Скажи прямо:

> Статику залити безкоштовно легко. Node — з обмеженнями. А **SQL Server
> у безкоштовних тарифах не дає ніхто**. Це комерційний продукт Microsoft,
> і найдешевший варіант у хмарі коштує десятки доларів на місяць.

Питання класу: **то що робять у реальності?**

Відповіді, які варто розібрати:

1. **Платять.** Найчастіше. Хостинг бази — стаття витрат будь-якого проекту.
2. **Беруть іншу СКБД.** PostgreSQL і MySQL мають безкоштовні хмарні тарифи. SQL із блоку 1 переноситься майже без змін — пам'ятаєте таблицю відмінностей у дні 10? `TOP` проти `LIMIT`, і майже все.
3. **Ставлять свій сервер.** Школа могла б підняти власний, але це вже адміністрування, не розробка.

⚠ Це і є закриття обіцянки з дня 10:

> Тоді я казав: «SQL у всіх СКБД практично однаковий, вивчивши одну,
> за день розберешся з іншою». Зараз ви бачите, **нащо** це знання потрібне.
> Вибір СКБД — це рішення, яке впливає на те, чи зможете ви взагалі
> опублікувати продукт.

### 15–28 хв. Що таке деплой 🗣

> **Деплой** — перенесення програми з комп'ютера розробника туда, де нею
> користуються люди.

Що для цього потрібно, крім самого коду:

**1. Змінні середовища.**

Питання класу: у вас пароль до бази в `.env`, і цей файл **не** в Git. Як він потрапить на сервер?

Відповідь: не потрапить. На сервері змінні задаються **в налаштуваннях хостингу**, окремо від коду.

⚠ Це і є причина, чому `.env` не в Git — не тільно секретність, а й те, що **у кожного середовища свої значення**:

| Середовище | `DB_SERVER` |
|---|---|
| комп'ютер учня | `localhost` |
| тестовий сервер | `test-db.internal` |
| робочий сервер | `prod-db.internal` |

Один код, різні налаштування. Саме тому `.env.example` у Git, а `.env` — ні.

**2. Порт і адреса.**

```typescript
const PORT = process.env.PORT || 3000;
```

Хостинг сам вирішує, який порт дати. Програма мусить його спитати, а не вимагати свій.

**3. Збірка.**

У них Node виконує `.ts` напряму, збірки немає. Але React із дня 26 (у кого був) — потребує `npm run build`. Скажи, що це нормальна частина деплою.

**4. Постійна робота.**

Якщо ви закриєте термінал — сервер зупиниться. На хостингу цим займається окрема система, яка перезапускає програму при падінні.

### 28–38 хв. Секрети: остання розмова 🗣

Це третій раз за курс, і варто зібрати все разом.

| Де було | Що |
|---|---|
| день 15 | пароль до бази → `.env`, `.gitignore` |
| день 24–25 | пароль на сервері, ніколи не в коді браузера |
| **сьогодні** | правила для деплою |

Головне питання класу: **чому не можна покласти пароль до бази в `app.js`?**

Відповідь, яку варто витягти з класу, а не сказати: `app.js` **завантажується в браузер**. Будь-хто натисне F12 і побачить його. Це не «складно зламати» — це просто відкритий текст.

⚠ Покажи на проекторі: F12 → Sources → їхній `app.js`. Ось він, повністю.

> **Правило: усе, що потрапляє в браузер, — публічне.** Немає способу
> це змінити.

Звідси наслідок, який стосується їхнього коду:

> Тому запити до бази робить **сервер**, а браузер звертається до сервера.
> Це не архітектурна прикраса — це єдиний спосіб не віддати пароль усім.

І скажи, куда це веде далі:

> Якщо колись у вас з'явиться ключ до AI-сервісу або платіжної системи —
> правило те саме. Ключ живе на сервері. Браузер просить сервер, сервер
> просить сервіс.

### 38–45 хв. Архітектура системи: підсумок 🗣

Останні хвилини — зібрати весь рік в одну картинку.

```
   БРАУЗЕР                СЕРВЕР                        БАЗА
   ┌──────────────┐      ┌─────────────────────┐      ┌────────────┐
   │ index.html   │      │ server.ts  маршрути │      │ teachers   │
   │ style.css    │◄────►│ logic.ts   логіка   │◄────►│ clubs      │
   │ app.js       │ HTTP │ models.ts  класи    │ SQL  │ students   │
   │              │ JSON │ db.ts      доступ   │      │ enrollments│
   └──────────────┘      └─────────────────────┘      └────────────┘
      день 18–23             день 11–16, 24–29          день 3–10
```

Питання класу для завершення: **скільно з цього ви зробили самі?**

Усе. Скажи це вголос — вони не усвідомлюють обсягу.

Остання теза, яка має практичну цінність:

> Ця структура — не наша вигадка. Так побудований майже кожен веб-сервіс,
> яким ви користуєтесь. Різниця в масштабі, не в ідеї.

І одна фраза про тренди, бо держпрограма їх згадує: сучасні системи розбивають серверну частину на багато невеликих сервісів (мікросервіси), а частину роботи переносять у хмарні функції. Але базова схема «клієнт — сервер — база» залишається тією самою.

## Що піде не так

- **Проект не відтворюється.** Це очікуваний і корисний результат. Дай час виправити — це важливіше за решту частин.
- **Розчарування, що деплою не буде.** Прозвучить. Відповідь чесна: справа не в тому, що це складно, а в тому, що SQL Server у безкоштовних тарифах не дає ніхто. Це реальне обмеження, і воно саме по собі — урок про вибір технологій.
- **База зламалась і не відновлюється.** Найгірший сценарій. Резерв: у курсовому репо є `01-create-demo.sql` — можна працювати на демо-базі до захисту. Скажи це заздалегідь, щоб не панікували.
- **README перетворюється в переказ уроків.** Вимагай формат із завдання: як запустити, що вміє, чого не вміє.
