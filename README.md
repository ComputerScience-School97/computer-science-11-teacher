### Мінус спільної оцінки і як його закрити

Якщо в парі один сильний і один слабкий, обидва отримають однакову оцінку.

Рішення — **усна перевірка** в кінці роботи, 2 хвилини на пару, питання
**кожному окремо** по їхньому власному коду:

- першому: *що робить цей рядок з `ON`? Що буде, якщо його прибрати?*
- другому: *чому тут `return`, а не `console.log`?*

Це не окрема оцінка, а право знизити спільну на 1–2 бали конкретному учню,
який не може пояснити здану роботу.

⚠ **Скажи класу про усну перевірку на початку роботи.** Це різко підвищує
участь обох. У завданні також прописано міняти того, хто друкує, на кожній частині.

## ⚠ День 15 — головний технічний ризик курсу## ⚠ День 15 — головний технічний ризик курсу

Драйвер Node **не вміє** Windows-автентифікацію так, як SSMS. Потрібно ввімкнути
змішаний режим (Mixed Mode), створити логін SQL Server і **перезапустити службу** —
останнє вимагає прав адміністратора.

**Перевір на одній машині до уроку** (5 хвилин):

1. SSMS → права кнопка по сервері → Properties → Security → чи можна вибрати
   `SQL Server and Windows Authentication mode`
2. Права кнопка по сервері → **Restart** → чи проходить без помилки прав
3. `npm install mssql` у порожній папці → чи не блокує мережа npm

Якщо крок 2 або 3 не проходить — у файлі учня є **повний резервний план**:
дані експортуються з SSMS у JSON (`FOR JSON PATH`), програма читає їх через `fs`.
Головна ідея дня («дані приходять зовні, а не написані в коді») зберігається.

Частини 3 і 5 у файлі учня продубльовані як 3-А/3-Б і 5-А/5-Б.
**Скажи класу на початку уроку, за яким планом працюєте.**

## Технічні особливості SQL Server, які треба тримати в голові

| | |
|---|---|
| Кирилиця | тільки `NVARCHAR`, і префікс `N` перед текстом: `N'Іваненко'`. Без нього літери псуються — це головна пастка блоку 1 |
| Обмеження кількості | `SELECT TOP 5`, а не `LIMIT 5` (більшість прикладів в інтернеті будуть з `LIMIT`) |
| Автонумерація | `IDENTITY(1,1)`, а не `AUTO_INCREMENT` |
| `GO` | розділювач частин скрипта, особливість SQL Server |
| Виконання в SSMS | **F5** без виділення виконує **весь аркуш**. Щоб один запит — спочатку виділити мишкою |
| Ім'я сервера | `localhost` або `localhost\SQLEXPRESS`. Різне на різних машинах — запиши, де яке |
| Помилка про сертифікат | у вікні Connect to Server → `Encryption: Optional` |
| Object Explorer не оновлюється | права кнопка → **Refresh**. Нова база сама не з'явиться |
| Збереження аркушів | SSMS пропонує свою папку. Учні мають зберігати в `Documents\pc-NN\sql\`, інакше Git роботи не побачить — **найчастіша причина втрачених уроків** |
