# День 1. Комп'ютер, файли, термінал

**Блок 0 — Інструменти**

## Мета дня

До кінця дня кожна пара: розуміє, що таке шлях до файлу; вміє відкрити термінал і перейти в потрібну папку; має на машині Git, Node.js, VS Code і SSMS, що підключається до SQL Server.

Це найважливіший день року. Учень, який не розуміє різниці між `C:\Users\Student\Documents\project` і «Робочим столом», застрягне в жовтні, і ти не зрозумієш чому.

---

## Урок 1 — теорія (без комп'ютерів)

### 0–5 хв. Про що курс

Коротко, без пафосу. За рік зробимо працюючий сайт, який зберігає дані в базі даних. Не «вивчимо теми», а зробимо продукт. Покажи готовий приклад на проекторі — будь-який простий CRUD-інтерфейс.

Скажи одразу три речі:
- працюємо в парах, за одним комп'ютером
- усе зберігається в інтернеті, тому нічого не пропаде
- хто друкує — змінюється на кожному новому завданні

### 5–20 хв. Файлова система 🗣

Малюй на дошці дерево:

```
C:\
├── Windows\
├── Program Files\
└── Users\
    └── Student\
        ├── Desktop\
        ├── Documents\
        │   └── pc-07\
        │       ├── README.md
        │       └── notes.txt
        └── Downloads\
```

Ключові тези, кожну з прикладом на дошці:

1. **Файлова система — це дерево.** Один корінь, гілки, на кінцях файли.
2. **Шлях — це маршрут від кореня до файлу.** `C:\Users\Student\Documents\pc-07\README.md` читається як інструкція: зайди в `Users`, потім у `Student`, потім…
3. **Робочий стіл — це просто папка.** Не окреме місце. Це `C:\Users\Student\Desktop`. Момент, який дивує половину класу.
4. **Розширення — частина назви файлу.** `.txt`, `.md`, `.js`. Windows їх приховує за замовчуванням, і це джерело помилок: файл `script.js.txt` виглядає як `script.js`.
5. **Папка з програмою ≠ програма.** Пояснює, чому `git` може «не знайтись».

### 20–35 хв. Що таке термінал 🗣

Термін «командний рядок» не пояснює нічого. Пояснення, яке працює:

> Термінал — це той самий Проводник, тільки замість кліків ти пишеш словами. Він завжди «стоїть» у якійсь одній папці. Усе, що ти напишеш, стосується цієї папки.

Три команди на дошці з розшифровкою:

| Команда | Читається як |
|---|---|
| `cd Documents` | «зайди в папку Documents» |
| `cd ..` | «на один рівень вище» |
| `dir` | «покажи, що тут є» |

Питання класу для перевірки розуміння (усно, без комп'ютерів):

- Термінал стоїть у `C:\Users\Student`. Що покаже `dir`?
- Що станеться після `cd Documents`, а потім `cd ..`?
- Чому команда `dir` у папці `Desktop` покаже те саме, що ти бачиш на екрані?

### 35–45 хв. План на другий урок

Скажи прямо: «Ми не знаємо, що встановлено на цих комп'ютерах. Зараз ви це з'ясуєте самі, і ми запишемо на дошці». Це не імпровізація, це інженерна робота — так само роблять на новій роботі.

Намалюй на дошці таблицю на всю ширину. Її заповнює клас, кожна пара свій рядок:

| ПК | git | node | code | SSMS підключився | ім'я сервера | файли зберігаються |
|----|-----|------|------|------|------|------|
| 01 | | | | | | |
| 02 | | | | | | |

Скажи, що встановлювати вони будуть **самі, за інструкцією** — ти не ходиш по машинах. Інструкція в файлі `reference/install-guide.md`.

## Урок 2 — практика

### Крок 1. Відкрити термінал ⌨

**Win + R** → `cmd` → Enter.

⚠ Частина класу натисне Win і почне шукати мишкою. Це нормально, покажи обидва способи. Другий: у Проводнику в адресному рядку набрати `cmd` і Enter — термінал відкриється одразу в цій папці. Це трюк, який вони будуть використовувати весь рік.

### Крок 2. Пройтись по дереву ⌨

Продиктуй, вони виконують і дивляться на результат:

```
cd %USERPROFILE%
dir
cd Documents
dir
cd ..
```

Питання після кожної команди: «в якій папці ти зараз?» Відповідь видно ліворуч від курсору — покажи це, вони не помічають.

### Крок 3. Перевірка інструментів ⌨

```
git --version
node --version
code --version
```

SQL Server і SSMS так не перевіряються — вони не команди терміналу. Їх учні перевіряють, відкривши SSMS і спробувавши підключитись.

Кожна пара виходить до дошки і заповнює свій рядок: `+` або `—`.

### Крок 4. Перевірка запису файлів ⌨

```
cd %USERPROFILE%\Documents
echo test > test.txt
dir
```

Далі — найважливіша перевірка року. Попроси вийти з профілю Windows і зайти знову, потім:

```
cd %USERPROFILE%\Documents
dir
```

Якщо `test.txt` на місці — четверта колонка `+`. Якщо ні — це змінює логістику всього курсу, і краще знати сьогодні.

### Крок 5. Встановлення — самостійно ⌨

Учні працюють за `install-guide.md`, кроки 1–6. Твоя роль — не встановлювати, а ходити й відповідати на питання.

Скажи одразу про **дві програми**, бо це джерело плутанини на весь блок:
- **SSMS** — бази даних. Таблиці, дані, запити
- **VS Code** — код, схеми, Git

SQL Server у цьому наборі — третя річ, і в неї **немає вікна**. Вона просто працює у фоні. Учні цього не очікують і будуть шукати «програму SQL Server» у меню Пуск.

⚠ **Мережа.** 15 машин, що одночасно тягнуть інсталятори Git + Node + VS Code — це кілька гігабайт. Шкільний вайфай може не витримати. Два рішення:
- запускати класами по 5 пар з інтервалом
- або принести флешку з інсталяторами (найнадійніше)

**Якщо все вже встановлено** — учні одразу переходять до кроків 4 і 6 (розширення VS Code і підключення через SSMS), і в тебе залишається час почати день 2 раніше. Покажи `File → Open Folder` (саме папку, не файл) і вбудований термінал (**Ctrl + `**).

**Якщо мережі немає взагалі** — не втрачай урок на боротьбу з інсталяторами. Дай завдання за комп'ютером, воно не потребує інтернету:

- пройти від кореня `C:\` до своєї папки `Documents`, використовуючи тільки `cd` і `dir`, і назвати кількість кроків
- створити в `Documents` папку `test`, у ній файл, потім видалити обидва (`mkdir`, `echo`, `del`, `rmdir`)
- знайти, у якій папці лежить сам Проводник (`where explorer`)
- відкрити VS Code, створити файл, зберегти його в `Documents` і знайти його через `dir`

Встановлення переносиш на день 2.

## Що піде не так

- **Кириличні імена користувачів.** Якщо профіль — `C:\Users\Учень`, частина інструментів Node зламається пізніше. Дізнайся це сьогодні: `echo %USERPROFILE%`.
- **Пробіли в шляхах.** `cd My Documents` не працює без лапок. Покажи одразу: `cd "My Documents"`.
- **Хтось наберe `cd` і Enter.** Windows просто покаже поточну папку. Скажи, що це не помилка.
- **PowerShell замість cmd.** Виглядає інакше (синій), `dir` працює, `%USERPROFILE%` — ні (там `$env:USERPROFILE`). Простіше просто попросити відкрити `cmd`.
- **Темп.** Клас із нульовою базою пройде кроки 1–4 за 30 хвилин, не за 10. Не підганяй.
- **Термінал не перезапустили.** Після установки Git команда `git --version` не працює в **старому** вікні терміналу. Половина класу спитає про це. Скажи заздалегідь і напиши на дошці.
- **Ім'я сервера.** Головна складність дня, якщо SQL Server уже стоїть. Варіанти: `localhost`, `localhost\SQLEXPRESS`, `.\SQLEXPRESS`, `(local)`. Пройди по класу й запиши, який варіант на якій машині — ця табличка знадобиться весь блок 1.
- **SSMS ставиться довго.** 10–20 хвилин, іноді з перезавантаженням. Якщо його немає на машинах, весь другий урок піде на встановлення. Це нормально, плануй на це.
- **Шукають «SQL Server» у меню Пуск.** Не знайдуть — у сервера немає вікна. Скажи заздалегідь: відкривати треба **SSMS**.
- **Помилка про сертифікат** у вікні Connect to Server. Лікується `Encryption: Optional`. Це буде в половини класу, впиши на дошку одразу.
